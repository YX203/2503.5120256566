# 图书馆借阅管理系统（面向对象程序设计 C++）

西南科技大学《面向对象程序设计（C++）》课程实验，实验一 ~ 实验四。

## 一、项目结构

| 文件 | 说明 | 对应知识点 |
|---|---|---|
| `Resource.h/.cpp` | 图书资源**抽象基类**（纯虚函数、虚析构、操作符重载） | 实验三、实验四 |
| `Book.h/.cpp` | 普通图书（ISBN 校验） | 实验三：继承 |
| `Magazine.h/.cpp` | 杂志（期号、主编） | 实验三：继承 |
| `EBook.h/.cpp` | 电子资源（大小、下载链接，可多人同时借阅） | 实验三、实验四：虚函数重写 |
| `Reader.h/.cpp` | 借阅人**抽象基类**（借阅记录数组、借还业务） | 实验二、实验四 |
| `Student.h/.cpp` | 学生（学号、专业、年级，最多借 5 本） | 实验三：继承 |
| `Teacher.h/.cpp` | 教师（工号、职称、学院，最多借 10 本） | 实验三：继承 |
| `BorrowRecord.h/.cpp` | 一条借阅记录（借出/应还/归还日期、逾期罚金） | 实验二：组合 |
| `TimeUtil.h/.cpp` | 日期工具（含"模拟时间推进"，用于演示逾期） | 工具类 |
| `Library.h/.cpp` | 图书馆**组合类**，用基类指针数组统一管理资源与借阅人 | 实验二、实验三、实验四 |
| `main.cpp` | 主菜单与全部输入输出 | 全部实验 |

## 二、类的层次

```
Resource（抽象基类）
 ├── Book        普通图书   借期 30 天，逾期 0.2 元/天
 ├── Magazine    杂志       借期  7 天，逾期 0.5 元/天
 └── EBook       电子资源   借期  3 天，逾期 1.0 元/天（不限份数）

Reader（抽象基类）
 ├── Student     学生   最多借 5 本
 └── Teacher     教师   最多借 10 本
```

## 三、知识点覆盖

**实验一　类与对象**
- 类的设计、`private / protected / public` 访问控制
- 默认构造函数 + 重载构造函数
- 数据成员合法性校验（ISBN 13 位、价格/页数/数量非负、年级 1~5 等）
- 初始化、修改（set）、获取（get）、输出（print）基本操作
- 多文件组织

**实验二　组合关系与依赖关系**
- 组合：`Library` 包含 `Resource*[]` 与 `Reader*[]`；`Reader` 包含 `BorrowRecord[]`
- 依赖：`Reader::borrowResource(Resource& res)` 以另一个类的对象引用作参数
- 构造函数的初始化列表、析构函数统一释放资源

**实验三　继承与派生**
- 公有继承、派生类构造函数调用基类构造函数
- 派生类新增自己的数据成员与成员函数
- 资源的增加、删除、**增加数量**、**减少数量**、单条查询、全部显示
- `new` / `delete` 的使用

**实验四　多态性与虚函数**
- 基类中声明**纯虚函数** → `Resource`、`Reader` 成为抽象类
- 基类**虚析构函数**
- 用**基类指针数组**统一管理不同派生类对象，通过基类指针调用虚函数
- 派生类重写虚函数，同名函数表现出不同行为（借期、罚金、显示内容、
  电子资源不限份数）
- **操作符重载**：`operator<<`、`operator==`、`operator<`

## 四、编译与运行

用 Visual Studio 打开 `面向对象程序设计.slnx`（或直接打开 `.vcxproj`），
选择 `Debug | x64`，按 `F5` 运行。

源文件保存为 **UTF-8 with BOM**，在中文 Windows 控制台下可直接正常显示中文。

## 五、功能菜单

```
  1. 显示全部馆藏资源
  2. 添加新资源（普通图书 / 杂志 / 电子资源）
  3. 增加已有资源的数量
  4. 减少已有资源的数量
  5. 删除某一资源
  6. 查询某一资源的详细信息
  7. 按价格排序后显示馆藏
  8. 添加借阅人（学生 / 教师）
  9. 显示全部借阅人
 10. 借阅资源
 11. 归还资源（自动计算逾期罚款）
 12. 查看逾期情况
 13. 查看全部借阅记录
 14. 查看图书馆统计信息
 15. 模拟时间推进（用于演示逾期罚款）
  0. 退出系统
```

> 演示逾期罚款时，先借出一本书，再用菜单 **15** 把时间推进 40 天，
> 然后选 **12** 查看逾期汇总、选 **11** 归还，即可看到按天计算的罚金。
